Game Features

This version is designed for two people sharing one screen. The controls are simple, the game status is easy to follow and the layout adjusts to different screen sizes.

🎮 Two-player turns

Players take turns placing X and O on the same 3 × 3 board.

🏆 Live scoreboard

Track Player X wins, Player O wins and drawn rounds.

✨ Winning-cell highlight

The three cells that complete a winning line are highlighted.

🔊 Optional sound effects

Hear different sounds for moves, wins, draws and starting a new round. Sound can be turned off.

🔁 Next-round rule

The previous winner starts the next round. After a draw, the starting player alternates.

📱 Responsive layout

The game board, buttons and navigation adjust for phones, tablets and desktop screens.

💾 Saved scoreboard

The scoreboard, next starting player and sound preference are saved in browser storage on the same device.

♿ Keyboard-friendly controls

Board squares and action buttons are standard buttons that can be reached using a keyboard.
